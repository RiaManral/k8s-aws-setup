# Kubernetes on AWS- Learning Project

A hands-on project building a private, multi-node k3s cluster on AWS-first manually, then via Terraform- covering networking, IAM, SSM access, CI/CD, and Kubernetes core components.

## Structure
- `terraform/` — Infrastructure as Code (US East region)
- `ansible/` — Configuration management playbooks
- `docs/` — Architecture notes and manual setup documentation (AP South region)
- `scripts/` — Operational scripts (start/stop automation)
